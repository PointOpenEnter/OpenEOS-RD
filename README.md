# OpenEOS — Open Shutter Count Desktop Utility

[![Version](https://img.shields.io/badge/version-v0.4.2-blue.svg)](https://github.com/PointOpenEnter/OpenEOS-RD/releases)
[![License](https://img.shields.io/badge/license-MIT-green.svg)](LICENSE)
[![Platform](https://img.shields.io/badge/platform-Windows%20x64-lightgrey.svg)]()
[![Privacy](https://img.shields.io/badge/privacy-100%25%20Offline-brightgreen.svg)]()

**OpenEOS** — открытая автономная утилита для быстрого и безопасного считывания показаний счётчика срабатываний затвора (**Shutter Count**) современных цифровых фотокамер по метаданным RAW-файлов и снимков.

В отличие от сомнительных веб-сервисов, OpenEOS работает **строго локально на вашем компьютере**: файлы фотографий никуда не отправляются по сети, сохраняя полную конфиденциальность ваших снимков и авторских прав.

---

## 📷 Возможности и преимущества

* **Прямая поддержка Canon CR3 нового поколения:**  
  Считывает кумулятивный счётчик затвора из специализированной дорожки `Track4:ShutterCount` контейнера QuickTime/ISOBMFF в камерах процессоров **DIGIC X** (EOS R5, R6, R6 Mark II, R3, R7, R8, R10, R50, 1D X Mark III).
* **Широкая поддержка брендов и форматов:**  
  * **Canon:** CR2, CR3, JPEG, HEIC, HIF.
  * **Nikon:** NEF (включая Z-серию: Z5, Z6, Z7, Z8, Z9 и DSLR).
  * **Sony:** ARW (Alpha A7, A9, A1, A6xxx).
  * **Fujifilm:** RAF.
  * **Универсальные форматы:** DNG, PEF, JPEG.
* **База официальных паспортных ресурсов затвора:**  
  Автоматически подставляет гарантированный ресурс производителя для распознанной модели (например, `~500 000 кадров` для Canon EOS R6 Mark II) и наглядно объясняет разницу между механическим и электронным затвором.
* **Интерактивная справка (`?`):**  
  Всплывающее пояснение с защитой от случайного срабатывания (задержка удержания курсора 300 мс) о том, как устроен учёт спусков в цифровых камерах.
* **Пакетный анализ папок (Batch Mode):**  
  Сканирование сотен и тысяч снимков в фоновом потоке с отображением прогресс-бара, расчётом скорости (файлов в секунду), оценкой оставшегося времени и возможностью экспорта результатов в CSV.
* **Нативный тёмный интерфейс Fluent (Windows 11):**  
  Строго фиксированный размер окна (860 × 520), аппаратная интеграция с тёмной темой Windows DWM, отсутствие белых вспышек и артефактов при запуске.
* **Полная автономность (Portable Single EXE):**  
  Встроенный локальный движок на базе ExifTool и Strawberry Perl — программе не требуется установленный Python или внешний софт на ПК пользователя.

## 🖥 Внешний вид

Оболочка разработана с учётом визуальных гайдлайнов Windows 11 Fluent Design:
* Две сбалансированные вкладки: **«Проверить фото»** (мгновенное перетаскивание одного файла) и **«Анализ папки»** (пакетная таблица с сортировкой).
* Крупное, легко читаемое показание счётчика.
* Информационные блоки: модель камеры, точная дата съёмки кадра и официальный ресурс механического узла.
* Фирменная иконка фотоаппарата в заголовке и на панели задач Windows.

## 🚀 Быстрый старт

### Вариант 1: Готовый исполняемый файл (EXE)
1. Скачайте последний релиз `OpenEOS.exe` со страницы [Releases](https://github.com/PointOpenEnter/OpenEOS-RD/releases).
2. Запустите файл на Windows 10/11 x64.
3. Перетащите ваш RAW-файл в область загрузки или нажмите **«Выбрать файл…»**.

### Вариант 2: Запуск из исходного кода
Для запуска требуется установленный Python 3.10+:

```bash
# Клонирование репозитория
git clone https://github.com/PointOpenEnter/OpenEOS-RD.git
cd OpenEOS-RD

# Установка зависимостей интерфейса
pip install tkinterdnd2

# Запуск приложения
python openeos.py
```
*(Примечание: для автономной работы в dev-окружении также требуется ExifTool в `C:\Tools\ExifTool` или рядом со скриптом).*

## 🛠 Самостоятельная сборка EXE

Сборка полностью автоматизирована через скрипты в папке `packaging/`:

```cmd
build.bat
```

Скрипт выполнит:
1. Генерацию векторных мульти-размерных иконок камеры (`app_icon.ico` и `app_icon.png`).
2. Подготовку портативного исходника с явным пробросом Perl `@INC`.
3. Сборку одного бинарника `dist\OpenEOS.exe` через PyInstaller без консольного окна.

Подробнее о структуре сборщика читайте в [`packaging/README.md`](packaging/README.md).

## 🔒 Конфиденциальность и безопасность

OpenEOS строго соблюдает цифровую гигиену:
* Никаких сетевых запросов: программа работает при отключенном интернете.
* Исходные файлы открываются **только для чтения** (`read-only`): модификация RAW-файлов и запись в камеру исключены.
* В репозитории не хранятся персональные данные, серийные номера и пользовательские тестовые снимки.
