# Методология тестирования OpenEOS (Testing Guidelines)

В этом документе описаны обязательные тест-кейсы, которые необходимо выполнить перед выпуском любого релиза (`Release`) или слиянием Pull Request в ветку `main`.

---

## 📋 Чек-лист предрелизной проверки

Каждый релизный бинарник `OpenEOS.exe` обязан пройти следующие тесты на Windows 10 или Windows 11 x64:

### 1. Тест запуска и графической подсистемы (Startup & Theme)
* [ ] **Отсутствие белой вспышки:** при первом запуске программы окно открывается сразу в тёмном стиле `#1F1F1F` с тёмным нативным заголовком Windows 11.
* [ ] **Отсутствие непрорисованных белых областей:** текстовые метки (`ПОКАЗАНИЕ СЧЁТЧИКА ЗАТВОРА`, статус, колонки) прорисованы сразу, нет белых прямоугольников.
* [ ] **Фиксация геометрии:** окно строго 860 × 520 px. Кнопка максимизации в заголовке отключена. Попытка растянуть окно за рамку мышью не меняет размер.
* [ ] **Иконка на панели задач:** процесс Windows отображает фирменную иконку фотоаппарата, стандартное синее перо Tkinter отсутствует.

### 2. Тест переключения темы (Theme Toggle)
* [ ] **Переключение в светлую тему:** нажать кнопку «☀️ Светлая» в верхнем правом углу. Окно плавно перестраивается в светлые тона `#F9F9F9`.
* [ ] **Отсутствие ложного моргания тултипа:** при нажатии на кнопку темы всплывающая подсказка рядом со счётчиком **не появляется**.
* [ ] **Возврат в тёмную тему:** нажать кнопку «🌙 Тёмная». Окно возвращается в исходный тёмный режим.

### 3. Тест одиночного снимка (Single Photo)
* [ ] **Проверка через диалог выбора файла:** нажать «Выбрать файл…», указать валидный тестовый снимок (например, Canon CR3). Счётчик считывается моментально, статус меняется на `● Готово`.
* [ ] **Проверка Drag-and-Drop:** перетащить один RAW-файл из Проводника в карточку загрузки. Файл считывается сразу без модальных окон с предупреждениями.
* [ ] **Проверка ресурса камеры:** для Canon EOS R6 Mark II отображается ресурс `~400 000 кадров` (не 200 000!).
* [ ] **Проверка интерактивного тултипа:** навести курсор на `(?)` рядом с «РЕСУРС ЗАТВОРА». Через 300 мс открывается структурированная справка. При уходе курсора справка закрывается через 160 мс. При клике на `(?)` подсказка переключается мгновенно.

### 4. Тест пакетного анализа (Batch Mode)
* [ ] **Выбор каталога:** перейти на вкладку «Анализ папки», нажать «Выбрать папку…». Путь отображается в поле.
* [ ] **Анализ:** нажать «Анализировать папку». Появляется прогресс-бар, процент выполнения, текущая скорость и имя обрабатываемого файла.
* [ ] **Прерывание анализа:** нажать «Прервать анализ». Процесс останавливается в течение 1–2 секунд, в таблице остаются уже прочитанные файлы, зависших процессов `perl.exe` в Диспетчере задач нет.
* [ ] **Экспорт CSV:** нажать «Экспорт CSV…», сохранить файл. Проверить, что CSV открывается в Excel / LibreOffice с корректной кодировкой UTF-8 BOM.

---

## 🔒 Политика работы с тестовыми сэмплами
* Запрещено загружать реальные пользовательские снимки в репозиторий GitHub.
* Тестирование проводится локально разработчиком. В PR указываются только хеши файлов и текстовые логи работы.
