# Особенности метаданных производителей (Protocol Findings)

В этом документе зафиксированы результаты низкоуровневого анализа структуры файлов RAW и метаданных ведущих производителей фототехники (Canon, Nikon, Sony).

---

## 1. Специфика Canon: TIFF (CR2) против ISOBMFF (CR3)

### Архитектурная разница форматов
* **Canon CR2 (до 2018 г.):**  
  Основан на классическом контейнере TIFF (1992 год). Метаданные хранятся в стандартных каталогах IFD (Image File Directory). Любая простая библиотека (включая стандартный PHP `exif_read_data()`) может прочитать базовые теги, однако данные о пробеге в большинстве зеркалок Canon намеренно скрыты производителем.
* **Canon CR3 (с 2018 г.):**  
  Построен на базе стандарта ISO Base Media File Format (**ISOBMFF / QuickTime / MP4**). Файл представляет собой иерархическое дерево атомов (боксов):
  * `ftyp` (тип файла: `crx `)
  * `moov` (заголовок контейнера фильма/медиа)
  * `trak` (медиа-дорожки: видео, аудио, превью, метаданные)
  * `uuid` (проприетарные структуры данных Canon)
  * `mdat` (бинарный массив сжатого RAW-сенсорного потока)

### Разделение поколений процессоров Canon: DIGIC 8 против DIGIC X

| Параметр | Поколение DIGIC 8 (2018–2019) | Поколение DIGIC X (2020+) |
| :--- | :--- | :--- |
| **Модели камер** | Canon EOS R, EOS RP, EOS M50, EOS 250D, EOS 90D | Canon EOS R5, R6, R6 Mark II, R3, R7, R8, R10, R50, 1D X Mark III |
| **Наличие дорожки Track4** | ❌ Отсутствует (только Tracks 1–3) | ✅ Присутствует (`Track4`) |
| **Тег `Track4:ShutterCount`** | ❌ Не записывается в файл | ✅ Записывается при каждом спуске |
| **Чтение по файлу снимка** | ❌ **Невозможно** (камера не вносит запись) | ✅ **100% поддерживается OpenEOS** |
| **Как узнать пробег** | Только подключением тушки кабелем USB по протоколу PTP | Из любого файла `.CR3` / `.JPG` в OpenEOS |

> **Важный вывод для R&D:**  
> Если для камеры Canon EOS R программа сообщает «Счётчик не найден» — это не программный сбой, а физическое свойство прошивки DIGIC 8. Для таких камер требуется разработка модуля прямого USB-подключения.

## 2. Специфика Nikon: MakerNotes и тег `0x00a7`

### Как устроен счётчик Nikon
* В камерах Nikon (как зеркальных DSLR, так и беззеркальных Z-серии) общее число срабатываний записывается в тег MakerNotes **`0x00a7 (ShutterCount)`**.
* **Кумулятивный характер счётчика:**  
  Счётчик Nikon является сквозным: он увеличивается на +1 при каждом спуске, **включая как механический затвор, так и полностью электронный (бесшумный) спуск**.
* **Развенчание мифа о «механическом счётчике» у Nikon:**  
  Некоторые онлайн-сайты (например, `shuttercounter.com`) называют эту строку *«Mechanical Shutter Count»* (в русском автопереводе — *«Количество механических затворов»*).  
  **Это заблуждение:** у флагмана **Nikon Z9** механического затвора нет физически (только электронный сенсор), однако в метаданных кадра тег `0x00a7` присутствует и исправно считает каждый сделанный кадр.

## 3. Режимы затвора (`ShutterMode`)

В современных беззеркальных камерах снимок может производиться в трех принципиально разных режимах:

1. **Mechanical (Механический затвор):**  
   Обе шторки (передняя и задняя) отрабатывают физически. Вызывает износ шторок.
2. **Electronic Front Curtain (EFCS / Электронная передняя шторка):**  
   Экспонирование начинается электронным сбросом матрицы, а завершается физической шторкой. Износ снижен в 2 раза.
3. **Electronic / Silent Shutter (Полностью электронный затвор):**  
   Шторки остаются открытыми, чтение построчное с матрицы. **Физический износ механического узла равен нулю.**

Тег `ShutterMode` фиксирует режим **конкретного кадра**, в то время как `ShutterCount` отображает общий пробег камеры со дня выпуска.
