# Архитектура OpenEOS (Architecture)

Документ описывает внутреннее устройство утилиты OpenEOS, распределение ответственности между подсистемами, управление потоками и механизмы межпроцессного взаимодействия.

---

## 🧱 Многоуровневая структура

OpenEOS спроектирован по модульному принципу с четким разделением презентационного слоя и слоя низкоуровневого анализа:

```
┌─────────────────────────────────────────────────────────────┐
│                    Презентационный слой                     │
│    (Tkinter + Fluent Dark Palette + DPI-Safe Layout)        │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                  Слой координации и потоков                 │
│  (Single Worker Thread / Batch Queue / threading.Event)    │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                 Слой нормализации метаданных                │
│    (Normalise Record / Shutter Ratings / Word Regex)        │
└──────────────────────────────┬──────────────────────────────┘
                               │
                               ▼
┌─────────────────────────────────────────────────────────────┐
│                 Движок анализа метаданных                   │
│   (Perl Runtime + ExifTool daemon session via -stay_open)   │
└─────────────────────────────────────────────────────────────┘
```

---

## 🔍 Детализация слоев

### 1. Движок анализа метаданных (`init_exiftool`)
* Для полной автономности OpenEOS упаковывается вместе со сборкой Strawberry Perl и дистрибутивом ExifTool.
* Функция `init_exiftool()` ищет рабочие компоненты в трёх местах:
  1. Каталог распаковки PyInstaller (`sys._MEIPASS`);
  2. Локальная папка с исполняемым файлом;
  3. Системный путь разработки `C:\Tools\ExifTool`.
* Запуск производится напрямую через `perl.exe -I lib_dir exiftool.pl` с явной передачей путей в `PERL5LIB`. Это предотвращает конфликт с поиском системных модулей Perl в среде Windows.

### 2. Пакетная сессия ExifTool (`-stay_open`)
* Вместо запуска отдельного процесса на каждый файл (что вызывало бы задержку 300–500 мс на один снимок), сканер использует постоянный процесс ExifTool, запущенный с ключами:
  ```
  -charset filename=UTF8 -stay_open True -@ -
  ```
* Файлы передаются блоками по `BATCH_CHUNK_SIZE = 50`. Команда завершается уникальным маркером `-execute{N}`.
* Это обеспечивает скорость чтения от **30 до 80 файлов в секунду** на SSD.

### 3. Слой многопоточности и отмены
* Все операции чтения выполняются в `daemon=True` потоках (`single_worker`, `batch_worker`).
* GUI Tkinter никогда не блокируется операциями ввода-вывода.
* Прерывание анализа реализовано через `threading.Event`: при нажатии кнопки «Прервать анализ» процесс ExifTool немедленно завершается или закрывает пайп, а таблица сохраняет уже обработанные блоки без повреждения данных.

### 4. Графическая оболочка Tkinter
* Окно имеет строго фиксированную геометрию `860 × 520 px` с системным запретом изменения размеров:
  ```python
  self.root.resizable(False, False)
  ```
* Заголовок интегрирован с Windows Desktop Window Manager:
  ```python
  DWMWA_USE_IMMERSIVE_DARK_MODE = 20
  ctypes.windll.dwmapi.DwmSetWindowAttribute(...)
  ```
* Для мгновенной отрисовки без белых артефактов принудительно вызывается системный Win32 API:
  ```python
  ctypes.windll.user32.InvalidateRect(hwnd, None, True)
  ctypes.windll.user32.UpdateWindow(hwnd)
  ```
