# OpenEOS v0.3.1 (Legacy Version)

Архивный снимок исходного кода версии **v0.3.1** (оригинальный светлый интерфейс).

---

## Особенности версии v0.3.1:
* Оригинальная светлая палитра (`#F3F6FA` / `#FFFFFF` / синий акцент `#2764D7`).
* Базовое чтение метаданных одиночного файла через Drag-and-Drop или диалог выбора.
* Сканирование каталогов с CR3-файлами в фоновом потоке.
* Таблица Treeview с сортировкой и экспорт отчёта в CSV.

## Запуск архивной версии:
```bash
python openeos_v0.3.1.py
```
*(Требует установленный `tkinterdnd2` и ExifTool в `C:\Tools\ExifTool\exiftool.exe`).*
